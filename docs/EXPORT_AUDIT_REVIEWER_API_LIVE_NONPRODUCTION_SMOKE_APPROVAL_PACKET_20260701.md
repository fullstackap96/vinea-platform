## Purpose

This packet defines the exact approval needed before running a live HTTP/browser smoke test of the already wired API-only export audit reviewer prototype in a safe non-production environment.

The smoke test is intended to validate `/api/export-audit-reviewer` through an actual authenticated app session after route-level test-harness QA has already passed.

This packet does not approve production monitoring, production export flags, production exports, dashboard UI, staff-facing production UI, migrations, operational RLS changes, Google Calendar changes, storage access, signed URL creation, raw export access, record mutation, or secret exposure.

The product owner must fill one approved non-production app target before QA begins:

- Denied document-manifest event fixture label: `SAFE_EXPORT_AUDIT_REVIEWER_DOCUMENT_MANIFEST_DENIED_EVENT`

Allowed audit actions under smoke:

- `export.request_list_basic.downloaded`
- `export.request_list_basic.denied`
- `export.request_document_manifest.downloaded`
- `export.request_document_manifest.denied`

Expected result:

- API reads only `audit_events`.
- API constrains rows to the selected active parish `parish_id`.
- API does not query export source tables such as `requests`, `request_documents`, `parishioners`, storage tables, or Google Calendar data.
- API returns read-model rows and filter summaries only.
- API writes no audit events and mutates no records.
